# Reporting a security problem

Thank you for looking. If you find a weakness that could put users at risk,
please **don't open a public issue**. Report it privately with GitHub's
"Report a vulnerability" button (Security tab of this repository), and give
us a reasonable time to fix it before disclosing.

For things already listed under "Known limitations" in the README, or for
questions and suggestions, public issues and discussions are welcome.

There is no bug bounty at the moment.
